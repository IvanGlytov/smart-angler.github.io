# Smart Angler - Карта глубин

## Как открыть карту локально

### Вариант 1: Простой HTTP сервер (рекомендуется)

```bash
# Перейдите в директорию smart-angler.github.io
cd smart-angler.github.io

# Запустите простой HTTP сервер (Python 3)
python3 -m http.server 8000

# Откройте в браузере:
# http://localhost:8000
```

### Вариант 2: Через Telegram Mini App

1. Убедитесь, что файлы загружены на GitHub Pages или другой хостинг
2. Настройте URL Mini App в настройках бота
3. Откройте карту через бота

### Вариант 3: Прямое открытие файла

⚠️ **Не рекомендуется** - могут быть проблемы с CORS при загрузке GeoJSON

Просто откройте `index.html` в браузере (двойной клик)

## Структура файлов

- `index.html` - главная страница карты
- `map.js` - логика отображения карты и глубин
- `all_depths.geojson` - данные глубин (хранится в Git LFS)
- `merged_depths.geojson` - объединенные данные (резервный файл)
- `desna_depths.geojson` - тестовые данные

## Настройка Git LFS

Если файл `all_depths.geojson` большой (>100MB), он должен быть в Git LFS:

```bash
# Проверьте, что файл отслеживается LFS
git lfs ls-files

# Если файл не в LFS, добавьте его:
git lfs track "*.geojson"
git add .gitattributes
git add smart-angler.github.io/all_depths.geojson
git commit -m "Add large GeoJSON file via LFS"
```

## Развертывание на GitHub Pages

1. Убедитесь, что репозиторий настроен для GitHub Pages
2. Загрузите файлы в ветку `main` или `gh-pages`
3. Включите GitHub Pages в настройках репозитория
4. Карта будет доступна по адресу: `https://yourusername.github.io/smart-angler.github.io/`

## Устранение проблем

### Файл не загружается

- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что файл `all_depths.geojson` существует
- Проверьте, что используется правильный путь к файлу в `map.js`

### Карта пустая

- Проверьте, что GeoJSON файл содержит данные
- Убедитесь, что координаты в правильном формате [lon, lat]
- Проверьте ограничение на количество точек (maxPoints в map.js)

### Медленная загрузка

- Файл 1.9GB очень большой для веб-загрузки
- Рекомендуется использовать оптимизацию или тайлы
- Запустите `optimize_geojson.py` для уменьшения размера
